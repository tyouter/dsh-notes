# 需求清单

> 这些需求不是一次给出的，是从多轮试用里逐步收敛出来的。编号只是为了在问题/进度里引用。
> 状态：✅ 已实现并验证 · ⚠️ 已实现但依赖模型判断 · ⬜ 未做

## 目标形态

一页笔记旁边有一个**会客厅**：写东西时，屋里坐着一位召唤师和若干客人。召唤师负责调度，
客人负责回应；所有话都落在正文里，而不是飘在界面上。

## 非目标（这一轮明确不做）

- 召场 UI（头像/形象）——用户明确说"形象先不做"
- 发布会/版本升级——功能不成熟，只 push 不发布
- 多轮自动互相辩论——discuss 目前是单轮（每人一句）
- 在别处（聊天、历史页）使用会客厅

## 关键验收场景（人工）

1. 「今天取了快递，买了两斤橘子」→ 不打扰。
2. 「我想了解西域开通的历史，可以找谁？」→ 召唤师报名字，那位客人开口。
3. 「让乔布斯来，现在说」→ 乔布斯直接以引用回答。
4. 「这不是应该黄仁宇来回答我」→ 只有黄仁宇一条，没有召唤师台词。
5. 「你们俩讨论一下……」→ 召唤师开场，两位依次接话。
6. 说完一句立刻再说一句 → 中途不插话；停 2 秒才可能有人开口。
7. 点取消/保存 → 语音条消失，事后不再冒出引用。

## 一句话状态

麦克风打开后，写作页后面一直坐着一位**召唤师**：每次停顿它拿到整页上下文，判断作者是在写东西、
跟它说话、点名某位客人，还是让客人互相讨论，然后给出计划（在座、谁开口、差事、时机、台词）。
客人的话一律以 `> **名字**：…` 写进正文；语音条只显示状态。

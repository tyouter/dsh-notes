## 第二阶段：多人 + 造人（P2/P3）

- 计划支持最多 3 位；依次发言；每位客人独立记忆（说过什么、被忽略过、下次等多久）。
- `/voice/create`：按统一 schema 现造一位，写入 `personas.json`，`origin: "auto"`；设置页带「自动」标记。
- 限流：10 分钟最多造一位。

验证：一段混合文本命中 2 位；「明朝财政」文本造出黄仁宇并落到 personas.json。

## 第三阶段：召唤师（重写）

- 新增 `lib/convene.js`：一次调用返回计划 `mode / timing / say / seat / speak / dismiss / create / note`。
- 面板不再做语义判断（删掉 `wantsPartner` / `addressesRoom` / `asksNow` 等关键词逻辑）。
- 提示词把上下文拆成【作者先前写的】【屋里说过的】【作者刚刚说的这一句】。
- 召唤师可回答 `{"keep":true}`（维持房间、这一轮不出声）。
- 缓存：规则与名单放 system，在座/新文本放 user。

验证：四种场景（写作 / 点名 / 讨论 / 闭嘴）均产出正确 mode；错字点名也能认出。

## 第四阶段：试用反馈驱动的修补

| 现象 | 处理 |
| --- | --- |
| 鸠摩罗什自说自话 | 引用不再回流成作者正文；上下文分块 |
| 每段都抢话、同一句重复 | 每次停顿最多一条；相同行不重复插入 |
| 关闭语音条还在 | stop 清状态；提示 4.2 秒过期；取消/保存调 `endVoice()` |
| 取消后顶部冒引用 | generation 递增，在途计划/插话作废 |
| 只回"在"不开口 | host 台词后继续执行 `speak` |
| 客人被换掉/消失 | 房间取并集，只有 `dismiss` 离场 |
| 抢答、召唤师代答 | 指定某人 → reply + say 留空 + speak 只有他 |
| 空转写报错 | 静默；分段静音 500ms → 800ms |
| 说话被插话 | 2 秒静默闸门（从最后一次出声算） |

## 第五阶段：人格可编辑 + 子页面

- 预设与自建统一可编辑：`personas.json` 用同一个 id 覆盖预设（`edited` 标记）；删掉覆盖即还原。
- 设置页拆三个视图：主设置 / 人格列表 / 单人编辑；主页面只留「人格库 · 管理 →」。
- 路由：`voice/personas/save`、`voice/personas/reset`、`voice/personas/delete`。
- 面板标签改读宿主 `locale` 服务（`clientCtx.get('locale').getLocale().active`），切语言即生效。

验证：`npm test` 全绿；列表 4 预设 + 5 自建；打开亚里士多德标题为 "Edit preset"；改名保存后行上出现「已改」，再点「还原预设」回到原文。

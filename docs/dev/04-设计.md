# 设计说明

## 模块

```
宿主半侧（lib/，改动后 disable→enable 生效）
  index.js          注册服务、工具、命令、HTTP 面
  store.js          笔记存储（notes.json 真相，index.db 投影）
  api.js            /notes/api 路由分发
  convene.js        召唤师：建计划、校验计划、必要时造人
  personas.js       人格库、插话提示词、造人提示词、/voice/select 兼容
  settings.js       settings.json 读写与默认值
  speech.js         语音识别桥（SenseVoice 等）

浏览器半侧（src/ → node build.mjs → client.js）
  head.js           i18n、api 封装、格式化、样式
  board.js          记录页 / 看板 / 语音与召唤师的调度执行
  settings.js       插件页设置界面（plugins.bundle.config）
  panel.js          面板、slot 注册、模块包装
```

## 数据

```
<工作区>/notes-vault/
  notes.json        笔记（真相）
  settings.json     enabled / mode / personaId / autoCreate / maxGuests
  personas.json     自建与自动生成的人格卡（origin: preset|custom|auto）
  events.jsonl      埋点
  index.db          SQLite 投影，可删
```

## HTTP 面（都在 `/notes/api`）

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| GET/POST | `/settings` | 读写开关 |
| POST | `/voice/convene` | 召唤师计划（核心） |
| POST | `/voice/interject` | 让某位客人说一句（可带 directive / discussion / focus） |
| POST | `/voice/select` | 旧的单人多选（兼容保留） |
| POST | `/voice/create` | 现造一位并落库 |
| GET/POST | `/voice/personas` | 人格库读写 |
| POST | `/speech/transcribe` | 转写（16k 单声道 WAV） |

## 计划（convene 的返回）

```json
{
  "mode": "host | reply | discuss | listen",
  "timing": "now | pause",
  "say": "召唤师自己要说的话，80 字内",
  "seat": ["在座的全部 id"],
  "speak": [{ "id": "这一轮开口的 id", "directive": "这次只做哪一件事" }],
  "dismiss": ["请他走的人"],
  "create": { "name": "名单外的人", "field": "领域", "why": "为什么请他" },
  "note": "调试用"
}
```

- `seat` = 房间；`speak` = 这一轮开口的人。客户端房间取**并集**（只增不减，除非 `dismiss`）。
- `now` 表示这一轮要出声；`pause` 表示先排好人。
- `keep` 是独立答案：`{"keep":true}`，表示人/差事/时机都不变，这一轮不出声。

## 上下文分块

召唤师（system 稳定前缀 + user 动态）：

```
system: 角色｜判断规则｜差事写法｜候选名单｜JSON 格式
user:   现在在座｜上一份差事｜你上一轮说过
        【作者刚刚说的这一句】
        【作者先前写的】
        【屋里已经说过的】（他们自己的话，只作背景）
```

客人插话（system + user）：

```
system: persona.brief｜主持人差事｜场景与规则
user:   【作者先前写的】【你们在屋里说过的】【作者刚刚说的这一句】
        （discuss 时另有"刚才屋里说的"）
```

引用都写成 `> **名字**：内容`，落在当前光标处。

## 客户端时序

```
开麦 → 电平检测 → 说话段 → 静音 800ms → 转写 → 落字（不说）
     → 继续说话？重置计时
     → 最后一次出声后静默 2s（DICTATION_PARAGRAPH_PAUSE_MS）
     → pauseTurn：调 /voice/convene（focus = 最近一段）
     → speakPlan：插 say → 依次让 speak 里的人开口
```

## 闸门与上限

| 名字 | 值 | 作用 |
| --- | --- | --- |
| `VOICE_COMMIT_MS` | 800ms | 一段语音结束的静音阈值 |
| `DICTATION_PARAGRAPH_PAUSE_MS` | 2000ms | 房间可以开口前的静默 |
| `PERSONA_BASE_GAP_MS` | 45s | 同一位客人的最小间隔（非强制回合） |
| `PERSONA_PAUSE_MS` | 25s | 任意两条插话的最小间隔 |
| `PERSONA_MIN_NEW_CHARS` | 220 | 非强制回合要求的新字数 |
| `PERSONA_MAX_REMARKS` | 1 | 每次停顿最多一条（discuss 例外） |
| `PERSONA_CREATE_MS` | 10min | 自动造人的限流 |
| 房间上限 | 5 | 客户端并集截断 |

强制（`timing: now`）回合跳过间隔与字数闸门，但仍要求页面非空，且同一句不重复插入。

## 取消 / 保存

`endVoice()`：停录音、abort 在途转写、清状态条、递增 `generation`。
在途的 convene/interject 回来时发现 generation 变了，直接丢弃——所以取消后不会再冒引用。

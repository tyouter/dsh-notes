# dsh-notes：给写完的人，一个不打断你的写作工具

## 一句话

**为那些脑子里有东西、但讨厌被工具打断的人而作。** 典型痛点是：打开工具比想法还慢，格式要学，AI 一开口就抢方向盘。它给的体验是——**打开就是一张纸，你只管写；排版、整理、翻译都在旁边等你叫。**

---

## 场景 · 痛点 · 需求 · 功能

### 1｜想法来了，要立刻写下来

- **场景**：开会、通勤、读到一半，脑子里冒出一句话。
- **痛点**：打开一个"写作工具"要先选模板、学 Markdown、找工具栏；等准备好，想法已经跑了。写顺了还要回头整理格式。
- **需求**：零学习成本；手不用离开键盘；格式别来烦我。
- **功能**
  - **打开就是一页纸**：没有模板选择，光标就在该在的位置。
  - **极简写**：两个空格就是项目符号，再缩进就是下一级；Enter 自动续同一级，Backspace 逐级退回，一级再退就变回正文。TAB 不用于缩进。
  - **实时排版**：右边不是"预览按钮"，它一直在排版——标题、列表、层级边写边成型。

### 2｜写着写着卡住，或者要改一段

- **场景**：一段话写到一半断了；或者一段已经写好，但想换个写法、换个语言。
- **痛点**：一停就冷场；让 AI 接手，它容易替你写完整篇、改掉你的语气，还编出你没说过的事实。
- **需求**：只在我卡住时出现；只听我的；错了一下就能撤回。
- **功能**
  - **补全**：停手 1 秒才出现；笔记自己的重复用词先答（不花一次调用），其次才问模型；TAB 一段一段采纳，采纳的文字是绿色标记，**一次 Backspace 整段收回**；不复述你已经写过的内容。
  - **自动写作开关**：关掉就不出现建议，也不消耗 token。
  - **选段结构化**：只处理你选中的那几行，结果作为草稿落在右页，原文一个字不动；**应用**才写回笔记。
  - **翻译**：整篇或选区，翻完仍可放弃或应用。
  - **保存**：保存的就是右边这一页。

### 3｜写过的笔记，别落灰

- **场景**：三周后想找"当时那个结论"，只记得写过。
- **痛点**：笔记越写越多，越写越不敢翻；它们只是安静的坟场。
- **需求**：能找、能再用、能带走。
- **功能**
  - **历史页**：可拖宽的列表、两行卡片、按天分组；编辑复用记录页的左右两页，不是第二个编辑器。
  - **复制 Markdown**：一键把整条笔记变成标准 Markdown（`#` 标题、`1.` 编号、`-` 列表），直接粘给别的 agent。

---

## One more thing：看板，让笔记不再落灰

看板把"你的笔记"变成可以提问的东西：

- **统计**：写作节奏、AI 使用、标签分布——直接来自笔记本身。
- **原生会话**：右栏是真的 agent 会话（带 `notes_query` / `notes_analyze` / `dashboard_chart` 工具），问"最近三周我在写什么"，它会去查库、给结论，并把图钉到看板上。
- 关键约束：**数字必须来自工具结果**，查不到就说查不到。

一句话：**写的时候它不打扰你，写完以后它替你记得。**
